# Project Scope & Feature Constraints

## Strict Scope Adherence
- Only implement features, components, and UI elements that are explicitly requested by the user.
- Do not assume, extrapolate, or introduce default eCommerce or application templates.

## Prohibited Transactional & E-commerce Elements
Unless explicitly requested by the user, **NEVER** add:
- Cart buttons or cart drawers/modals
- Checkout buttons or checkout flows
- "Buy it now" or purchasing action buttons
- Quantity pickers/selectors (`−`, `+`, quantity counters)
- Order actions, order status widgets, or transaction handling
- Payment badges, methods, or gateways (Visa, Mastercard, etc.)
